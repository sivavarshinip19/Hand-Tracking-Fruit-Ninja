# Hand-Tracking Fruit Ninja 🍉

A real-time Fruit Ninja game controlled by hand gestures using Python, OpenCV, MediaPipe, and Pygame.

## Features
- Real-time hand tracking using a webcam
- Fruit slicing with finger movements
- Score tracking and timer
- Colorful game interface and visual effects

## Technologies Used
- Python
- OpenCV
- MediaPipe
- Pygame

## How to Run
1. Install Python 3.11.
2. Clone or download this repository.
3. Install the required libraries:

   `pip install opencv-python mediapipe pygame numpy`

4. Run the game:

   `python handtrack_fruit_ninja.py`

5. Allow webcam access if prompted.

## Requirements
- A webcam
- Python installed on your computer
- Required Python libraries
